# 数据采集服务设计说明

本文记录设备数据采集服务的接口约定、存储策略与验收要求，供开发和测试人员共同维护。

## 背景与目标

现场设备每秒上报一次温度和转速。服务需要保留原始数据，并向监控页面提供最近一分钟的统计结果。

**设计目标**：输入可追溯、异常可定位、重试不产生重复记录。

> 本文中的容量与时间为设计示例，用于演示文档排版。

### 数据约定

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| device_id | string | 设备唯一标识 |
| timestamp | integer | 采样时间戳，毫秒 |
| temperature | number | 温度，摄氏度 |

### 请求示例

```json
{
  "device_id": "pump-001",
  "timestamp": 1789000000000,
  "temperature": 36.5
}
```

## 异常与重试

1. 校验必填字段，缺失时返回明确的错误原因。
2. 使用设备标识和采样时间组成幂等键。
3. 数据库暂时不可用时，将消息放回队列。
   - 最多重试三次。
   - 仍然失败时进入人工检查队列。

```python
def ingest(record):
    key = (record["device_id"], record["timestamp"])
    if not exists(key):
        save(key, record)
```
